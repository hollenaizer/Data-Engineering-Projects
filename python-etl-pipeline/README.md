\# Python ETL Pipeline



\## Project Overview



This project demonstrates the development of a beginner-friendly ETL (Extract, Transform, Load) pipeline using Python.



The purpose of this project is to practise extracting data from different file formats, preparing data for processing, and building a foundation in data engineering workflows.



\## Technologies Used



\- Python

\- Pandas

\- Excel

\- CSV

\- JSON

\- Git and GitHub

\## Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/hollenaizer/Data-Engineering-Projects.git

```



\### 2. Navigate to the project folder



```bash

cd Data-Engineering-Projects/python-etl-pipeline

```



\### 3. Create a virtual environment



```bash

python -m venv .venv

```



\### 4. Activate the virtual environment



Windows Git Bash:



```bash

source .venv/Scripts/activate

```



\### 5. Install dependencies



```bash

pip install -r requirements.txt

```



\## Running the Project



Run the extraction script:



```bash

python extract.py

```
